The Open CAS Framework (OCF) is a high performance block storage caching
meta-library written in C. It is the foundation that Open CAS Linux and the
SPDK block device adapter build on.

Start with the [Quick Start](/ocf/quick-start/) to build and run the example
application, or read the [design documentation](/ocf/design/) for how OCF works
internally. The API reference is published separately at
[api.open-cas.com](https://api.open-cas.com/).
