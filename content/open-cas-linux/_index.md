Open CAS Linux provides kernel adapters to the [Open CAS Framework](/ocf/),
implementing a high performance, low latency caching solution for Linux.

This administrator guide covers installation, configuration and day-to-day
operation. If you just want a working cache as quickly as possible, start with
the [Quick Start](/open-cas-linux/quick-start/).
